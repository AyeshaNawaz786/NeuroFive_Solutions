================================================================================
📊 WHAT THE TRAINING SCRIPT DOES:
================================================================================

1. Loads dataset.csv (1000 match snapshots)
2. Cleans data (removes missing values)
3. Engineers 22 features from raw data:
   - runs_per_ball, wickets_per_ball, run_rate_gap
   - balls_played, progress_percentage, wickets_lost
   - high_scoring_phase, death_phase, critical_moment
   - ... and 13 more features
4. Encodes categorical variables (team names → numbers)
5. Scales features (mean=0, std=1)
6. Splits data (80% train, 20% test)
7. Trains 3 models:
   - Logistic Regression (baseline)
   - Gradient Boosting
   - Random Forest (best)
8. Selects best model (Random Forest)
9. Saves 5 .pkl files to /models/

Total time: 2-5 minutes (depending on data size)

================================================================================
💡 TIPS:
================================================================================

• Sample dataset (1000 rows) = fast training, lower accuracy
• Real dataset (94k+ rows) = slow training, 98%+ accuracy

• For better accuracy:
  - Find more cricket data on Kaggle
  - Save as dataset.csv with same columns
  - Run cricket_win_predictor.py
  - It will train on your data automatically

• For production:
  - Use 50k+ real T20 matches
  - Follow same CSV format
  - .pkl files will be larger but more accurate

• To retrain with new data:
  - Replace dataset.csv
  - Run: python cricket_win_predictor.py
  - New .pkl files created automatically
  - App uses new files (no changes needed)
